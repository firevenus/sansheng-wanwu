# 三生万物 · 2304

> 道生一，一生二，二生三，三生万物。以 3 为底的 2048。

一款数字合并益智小游戏：滑动棋盘，方块相撞即**算术相加**（3+3=6，3+6=9，6+6=12……），目标是**正好**合出 **2304**（= 48²）。

## 玩法

| 项 | 规则 |
|---|---|
| 棋盘 | 4×4 |
| 合并 | 任意两块相撞即相加（不是 2048 的同数合并） |
| 刷新 | 每步 1 块：80% 为 3，20% 为 6 |
| 胜利 | **正好**合出 2304，步数越少越好（模拟基准：625–653 步） |
| 超额 | 越过 2304 不算通关，会提示超出多少，可选择重开或继续滑 |
| 死局 | 不存在——游戏比拼的是效率（步数），无尽模式规划中 |

## 与 2048 的区别

1. **合并是加法**：数值按算术和增长，效率路线是"对半合并"（≈每步翻倍，阶梯 3·2ⁿ）。
2. **永无死局**：任何局面都能继续合并，因此核心乐趣是"用最少步数合出目标"。
3. **精确凑数才算赢**：自由相加让任意 3 的倍数都可达，所以"最大块"本身不值钱——胜利条件是**正好 2304**。多合一个 3 就变成 2307，本局作废；最后几步得收着走，残局像凑账一样补差价。

## 数值特征

每步刷 1 块，期望注入 3.6 的材料，而合并守恒、永不死局，所以最大块几乎等于累计材料（模拟中材料利用率 99.4%–99.9%）：

| 步数 | 最大块中位数 |
|---|---|
| 300 | 1077 |
| 500 | 1800 |
| 640 | 2304（目标） |
| 1000 | 3600 |
| 2000 | 7200 |

也就是说**没有几何上限**（不同于 2048 的 131072），玩多久决定能合多大。唯一的技术含量在于"别越过去"：随手乱合，越线的概率约 19%；刻意控制则能稳定落在 2304。

## 运行

纯静态单文件，无需构建：

```bash
# 直接双击 index.html，或
npx serve .
```

支持键盘方向键（WASD）与触屏滑动。

进度自动存在 `localStorage`（`ssww_state`），刷新或关掉页面再打开会接着上一局下；点「重新开始」才会清零。最高分存 `ssww_best`，精确通关的最少步数存 `ssww_bestmoves`。

## 测试

逻辑测试用 Node 跑，无需装依赖（自带极简 DOM 替身）：

```bash
node test/logic.test.js
```

34 项断言，覆盖开局刷新、加法合并与计分、合体方块的过渡收尾、精确通关（正好 2304）与超额两种结局、结算后锁盘、刷新续局、重新开始清档、满盘不死局。
