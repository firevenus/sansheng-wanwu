# 三生万物 · 2304

> 道生一，一生二，二生三，三生万物。以 3 为底的 2048。

一款数字合并益智小游戏：滑动棋盘，方块相撞即**算术相加**（3+3=6，3+6=9，6+6=12……），目标是合出 **2304**（= 48²，3 的倍数）。

## 玩法

| 项 | 规则 |
|---|---|
| 棋盘 | 4×4 |
| 合并 | 任意两块相撞即相加（不是 2048 的同数合并） |
| 刷新 | 每步 1 块：80% 为 3，20% 为 6 |
| 目标 | 合出 2304，步数越少越好 |
| 死局 | 不存在——游戏比拼的是效率（步数），无尽模式规划中 |

## 与 2048 的区别

1. **合并是加法**：数值按算术和增长，效率路线是"对半合并"（≈每步翻倍，阶梯 3·2ⁿ）。
2. **永无死局**：任何局面都能继续合并，因此核心乐趣是"用最少步数合出目标"。
3. **精确凑数**：自由相加让任意 3 的倍数都可达，残局要像凑账一样补差价命中目标值。

## 运行

纯静态单文件，无需构建：

```bash
# 直接双击 index.html，或
npx serve .
```

支持键盘方向键（WASD）与触屏滑动。
